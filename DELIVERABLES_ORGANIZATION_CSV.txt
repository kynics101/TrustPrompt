HOW IT WORKS
============

Before: Pattern-only detection
  Input: "I work at Acccenture"
  Extracted: ["Acccenture"]
  Problem: Doesn't match "Accenture", missed due to typo
  
After: CSV + Fuzzy matching
  Input: "I work at Acccenture"
  Extracted: ["Acccenture"]
  Validation: Fuzzy match to "Accenture" (distance=1)
  Output: { org: "Acccenture", matchedOrg: "Accenture", confidence: 0.75 }

Three-layer validation:
  Layer 1: Exact match (confidence: 1.0)
  Layer 2: Fuzzy match with typo tolerance (confidence: 0.75)
  Layer 3: Abbreviation validation (confidence: 0.80)


USAGE EXAMPLES
==============

Validate single org:
  detector.validateOrganization('apple inc');
  // → { isKnown: true, confidence: 1.0, reason: 'exact_match' }

Extract orgs from text:
  detector.extractContextualOrgs('I work at Google');
  // → [{ org: 'Google', confidence: 1.0, ... }]

Handle typos:
  detector.validateOrganization('Acccenture');
  // → { confidence: 0.75, reason: 'fuzzy_match', matchedOrg: 'Accenture' }

Validate abbreviations:
  detector.validateOrganization('AAPL');
  // → { confidence: 0.80, reason: 'abbreviation_match', matchedOrg: 'Apple Inc.' }


CONFIGURATION
==============

Loader:
  csvUrl: '/csv/organizations.csv'
  maxFuzzyDistance: 2 (1-3)
  minOrgLength: 2
  caseInsensitive: true
  enableLogging: false

Detector:
  enableFuzzyMatch: true
  fuzzyDistanceThreshold: 2
  minOrgLength: 3
  enableContextExtraction: true
  enableAbbreviationValidation: true

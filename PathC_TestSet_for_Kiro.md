# TrustPrompt Path C test set (names, job titles, organizations)

Source: the team's current dataset, sheet "Path C Tests" (161 rows). All sample data is fictional.
Purpose: expected results for checking Path C only. Use it to run each prompt through `TrustLinguisticDetector.scan()` and compare.

## How to read it
- **Should flag = yes:** every listed finding should be found. Tag mapping: Name = `nlp_person_name`, Job = `nlp_job_title`, Org = `nlp_organization`.
- **Should flag = no:** the scan should return **no** `nlp_*` finding at all.
- A finding that is not in the list counts as **spurious**. A listed finding that is missing counts as **missed**.
- Matching is case-insensitive. A finding matches if it covers the listed text with at most small differences such as a title (Dr, Ms) or end punctuation. A longer span with extra words counts as wrong.
- Ignore `gazetteer_*`, `ph_address`, `source_code`, regex and validator findings. Those belong to Paths A and B.
- Typos in the expected text (marked "fuzzy") are intentional. The scan is expected to match them.
- Rows marked **policy** depend on a group decision that is still open (context-awareness). Do not change code to satisfy them yet.
- Line breaks inside a prompt are written as `⏎`. A `|` inside a prompt is written as `\|`.
